# S-UI 快捷创建节点：开发测试版 dev.1

本包基于原版 S-UI 前端增加中文“快捷创建节点”对话框，不使用 1S-UI，不更换代理核心，不接入外部管理服务。代码尚未部署到任何用户 VPS。

**交付状态：基于正式版 v1.6.7 的开发测试包。** 含修改源码、前端构建、Linux x86_64 程序及全新安装脚本。真实 VPS、公开证书签发、PassWall2 和稳定性验收尚未完成；不能当作已安全审计的生产版本。具体已通过的验证见根目录 TEST_REPORT.md。

## 可以做什么

在“入站”页面点击“快捷创建节点”，选择协议，填写新 VPS 的 IP 或直连域名，然后生成并启用。端口默认避开面板已知端口，可以手动调整。

| 协议 | 自动完成 | 仍需首次准备 |
|---|---|---|
| Hysteria2 | 强密码、用户、入站、导入链接；内置 ACME 自动申请及续期；内部 BBR 自适应，不填写上下行带宽上限 | 提供直连子域名和邮箱；首次勾选确认解析、TCP 80 和证书服务条款 |
| VLESS + Reality + Vision | UUID、X25519 密钥、Short ID、TLS 对象、用户、入站和链接 | 填写并确认适用的 Reality 目标域名 |
| SOCKS5 | 用户名、强密码、入站、链接 | 选择仅本机或外部访问；外部访问需确认并限制防火墙来源 |

SOCKS5 默认监听 VPS 的 127.0.0.1，供服务器本机或 SSH 隧道使用，不能直接将这个地址当作 VPS 公网入口填进电脑浏览器。开启外部访问后仍强制认证。普通 SOCKS5 不提供隧道加密，也不会自动套用 Hysteria2。

Hysteria2 的 TLS 配置必须保留证书验证；不会自动生成带 insecure 标记的节点。自动模式使用核心内联 ACME 提供者，默认 Let’s Encrypt HTTP-01，证书目录为服务工作目录下的 certificates/域名；不使用 DNS API 密钥。签发和续期在后台运行，保存成功不表示证书已签发，需检查日志并实际连接。TCP 80 必须空闲且持续允许验证流量。此版本不自动设置系统 TCP BBR，不修改防火墙或云安全组，不设置运营商流量配额。Reality 目标域名不会被自动探测或替换。

## 安全与失败处理

- 使用原版面板登录会话和同源 API，不引入额外公网服务、管理账号或长期 API Token。
- 使用浏览器密码学随机数生成凭据，不将节点密码写入日志或浏览器持久存储。
- 创建前后检查核心运行状态；不能确认时停止或显示待检查状态。
- 创建顺序：可选 TLS 对象 → 用户 → **停用**的入站 → 回读确认用户绑定和凭据 → 提交启用。
- 失败后不自动重复写入，也不自动删除不确定状态的数据。界面显示本次节点名和检查提示。可能遗留新的 TLS、用户或停用入站，需要人工检查。
- 最后启用请求若网络中断，不能单凭前端判断服务端是否已执行，必须回面板确认。
- 面板端口检查只涵盖面板内的入站和端点。不能检测 Nginx、SSH 等其他进程占用；启用时仍可能端口冲突。
- “保存成功”不代表 VPS 线路、防火墙、证书或 Reality 目标已经通过实际连接验证。
- 这是一个可审阅的小范围修改，不等于经过独立安全审计。上游更新可能覆盖该功能或改变接口。

## 安装及验收

1. 本包只支持 Linux x86_64、systemd。安装前核对系统、CPU 和端口，已有安装会拒绝覆盖。其他架构需要另行构建。
2. 使用包内安装器：`sudo bash linux-amd64/install-local.sh`。不要在现有业务 VPS 上试装，不要执行原版自动更新覆盖此测试分支。
3. 服务名 sui-quick，程序位于 /opt/sui-quick，数据位于 /var/lib/sui-quick，管理凭据仅保存在 root 可读的 /root/sui-quick-access.json。
4. 程序以独立 sui-quick 用户运行，只授予绑定低端口的能力，系统目录只读；保留 AF_NETLINK 以读取网络接口。SQLite 动态扩展加载在编译时关闭。TUN/TProxy 等需要额外权限的功能不在此安装方案范围内。
5. 面板和订阅仅监听 127.0.0.1，通过 SSH 本地转发访问；不开放管理端口到公网。示例：`ssh -N -L 2095:127.0.0.1:2095 用户@服务器IP`，然后打开 http://127.0.0.1:2095/app/。
6. 腾讯云安全组/主机防火墙需单独放行 TCP 80 和节点端口。SOCKS5 默认仅本机，外部开放前限制来源。
7. 保存签发后的数据目录备份，并实测三种客户端、重启、续期和内存占用。安装器不安装 TCP BBR、不修改防火墙、不关闭 SSH。

本包尚未发布到公共下载地址，当前没有可直接粘贴的公网下载安装命令。完成实测后，再使用固定版本发布地址和校验值生成安装命令。

现有服务器与配置不在本次修改范围内。安装脚本未在真实 systemd VPS 上验收，若中途失败将停止并保留现场，不自动删库或重复初始化。
