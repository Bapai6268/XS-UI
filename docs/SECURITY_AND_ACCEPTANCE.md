# dev.3 安全与验收范围

用户明确选择公网后台：IPv4 TCP 2095，初始 HTTP。面板认证沿用上游会话/同源防护，随机管理员密码，独立低权限服务账户，系统目录只读，仅有绑定低端口能力。HTTP 登录未加密，不等同于已配置 HTTPS；长期使用需在设置中配置后台 HTTPS。本版未新增自动后台 HTTPS。

安装器自动安装所需依赖，下载固定 dev.3 包，以安装脚本中固定的 SHA-256 校验完整包，并拒绝非法归档条目。这不抵御仓库账号/安装脚本本身被攻破，应保护 GitHub 登录。

BBR 支持时启用，记录原值，失败尝试恢复；不支持时不升级内核。节点没有人为带宽限速。主机 UFW/firewalld 只追加默认端口，不清空原规则，云防火墙由用户手动放行。

初始凭据直接显示并保存在 /root/xs-ui-access.json，面板改密后该初始文件不会同步。请保护终端输出和数据库备份。公开源码/安装包不含实际 VPS 密码、节点私钥或证书私钥。

下一步在 LAX-CUPN Lite 验收：安装一条命令；公网后台登录；真实证书签发/续期；HY2/Reality/SOCKS5 认证及连通；PassWall2 导入；768 MB 运行内存与持续运行。已通过本地测试不代表这些实机项目已通过。停止继续改动腾讯云测试机。
